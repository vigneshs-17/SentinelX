# Security Policy

## Supported Versions

Only the latest release of SentinelX is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest | :x:               |

Users should update to the latest release or main branch commit to receive security fixes.

## Reporting a Vulnerability

If you discover a potential security vulnerability in SentinelX, please report it privately through GitHub's Private Vulnerability Reporting rather than opening a public issue or discussion:

1. Navigate to the repository's [Security Advisories](https://github.com/vigneshs-17/SentinelX/security/advisories) tab.
2. Click **Report a vulnerability** to open a private advisory draft.
3. Provide details to help us understand and resolve the issue:
   - Description of the vulnerability and its potential impact
   - Step-by-step reproduction instructions or proof-of-concept
   - Relevant log output, environment details, or packet captures
   - Suggested mitigations or patches, if any

Please do not report security vulnerabilities via public GitHub issues, discussions, or pull requests.

### Response Time

We handle vulnerability reports on a best-effort basis; we aim to respond within 7 days. Once verified, we will coordinate a fix and release an advisory.
